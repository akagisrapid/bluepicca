# パワーユーザー向けTL体験 ロードマップ

> ツイ廃・アルファツイッタラー（twicca / ShootingStar 使用経験者）目線での分析
> 作成: 2026-03-30 / 最終更新: 2026-11-05（#111〜#144 の反映、[2回目の体験検証](./tsuihai-simulation-report-2026-11-05.md)、ホーム TL の引っ張って更新・言語フィルタ・ユーザー検索・スレッド縦線）

## 基本方針

かつてのTwitterでできていた全機能の再現は不可能。ただし、Bluesky（AT Protocol）の仕組みを活かしながら**同等の体験**を実現することを目指す。

ツイ廃が求めるTLの本質は以下の3点：
- **TLを自分でコントロールできる**（twicca の思想）
- **TLを読む流れを止めずにアクションできる**（ShootingStar の思想）
- **文脈を失わずに会話を追える**（Twitterの会話ビュー）

## 🟢 残課題

### リストフィード

**なぜ必要か**
「この人たちの発言だけを流す」は twicca のリスト TL に相当する、ツイ廃の基本の使い方。カスタムフィードでは代わりにならない（自分で作った人選をそのまま流せない）。

**現状**
`app.bsky.graph.getLists` / `app.bsky.feed.getListFeed` を呼んでいないため、Bluesky で作ったリストを TL のタブとして開けない。

**実現方法**
- 自分のリストを `getLists` で取得し、フィード選択にカスタムフィードと並べて出す
- タブの中身は `getListFeed` で取得する（既読位置の記憶・フィルタはカスタムフィードと同じ仕組みに乗せる）

**関連ファイル**
- `bskyapp/Service/GetFeedApi.swift` / `GetUserFeedsApi.swift` — 同じ形で List 用の API を追加
- `bskyapp/ViewModel/ContentViewModel.swift` — タブの種類にリストを追加

**難易度：中**

---

### アプリ内の通知一覧

**なぜ必要か**
メンション・引用・いいね・リポスト・フォローはプッシュ通知で届くが、アプリ内であとから見返す場所が無い。下の「Replies」は自分の投稿への返信だけで、直近 50 件の通知から絞っているため、古いものは見えない。

**実現方法**
- `RepliesView` を通知一覧に広げ、種類ごとのフィルタ（返信・メンション・引用・反応・フォロー）を付ける
- `GetNotificationsApi` の cursor で続きを読み込む

**関連ファイル**
- `bskyapp/ViewModel/RepliesViewModel.swift` / `bskyapp/View/RepliesView.swift`

**難易度：中**

---

- **TL での動画サムネイル**: 今は「動画」のバッジだけ。サムネイルを出して判断しやすくする（難易度：低〜中）
