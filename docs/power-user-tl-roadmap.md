# パワーユーザー向けTL体験 ロードマップ

> ツイ廃・アルファツイッタラー（twicca / ShootingStar 使用経験者）目線での分析
> 作成: 2026-03-30 / 最終更新: 2026-07-01（ツイ廃シミュレーション検証を反映）

## 基本方針

かつてのTwitterでできていた全機能の再現は不可能。ただし、Bluesky（AT Protocol）の仕組みを活かしながら**同等の体験**を実現することを目指す。

ツイ廃が求めるTLの本質は以下の3点：
- **TLを自分でコントロールできる**（twicca の思想）
- **TLを読む流れを止めずにアクションできる**（ShootingStar の思想）
- **文脈を失わずに会話を追える**（Twitterの会話ビュー）

## 🟢 残課題

### 言語フィルタ

**なぜ必要か**
「この人の発言は見たいが、読めない言語の投稿は消したい」はツイ廃の定番需要。フォローした人の投稿の中から読める言語のものだけを表示する粒度制御は twicca 的 TLコントロールの延長線上にある。

**現状**
`PostRecord.langs` はすでに取得済みだが、フィルタには使われていない。

**実現方法**
- `ContentViewModel.validFeeds` のフィルタ条件に言語チェックを追加
- `SettingsView` に「表示する言語」の選択UIを追加（「全言語」「日本語のみ」「日本語＋英語」等）
- 言語未設定の投稿（`langs` が空）は通常通り表示

**関連ファイル**
- `bskyapp/ViewModel/ContentViewModel.swift` — `validFeeds` にフィルタ条件追加
- `bskyapp/View/SettingsView.swift` — 言語選択UIを追加
- `bskyapp/Model/Feed/PostRecord.swift` — `langs` フィールドはすでに存在

**難易度：低**
